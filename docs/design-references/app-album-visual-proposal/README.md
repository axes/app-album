# App Álbum — Visual Proposal Reference

Esta carpeta contiene referencias visuales externas utilizadas para definir y validar la línea gráfica de App Álbum.

## Archivos esperados

- `reference.html`
- `reference-light.png`
- `reference-dark.png`

## Propósito

Estos archivos son material de referencia visual.

No forman parte del código productivo ni deben ser usados directamente como implementación.

La línea gráfica finalmente adoptada por el proyecto debe quedar documentada en:

- `docs/UI_STYLE_GUIDE.md`

y reflejada en:

- `/dev/ui`

## Uso

Para trabajos de diseño y revisión visual, estas referencias pueden usarse como objetivo de comparación para:

- paleta;
- tipografía;
- radios;
- sombras;
- densidad;
- componentes;
- estados;
- layout;
- navegación;
- motion.
